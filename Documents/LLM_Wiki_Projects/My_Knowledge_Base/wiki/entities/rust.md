# Rust

## Facts

- 一种强调性能、类型安全、并发性和内存安全的通用编程语言。
- 首次发布于2012年1月19日，当前稳定版本为1.95。
- 采用MIT和Apache 2.0双重开源许可证。
- Rust编程语言的官方开发者与维护团队。
- 作为 Tauri 的后端编程语言。
