# Graydon Hoare

## Summary

Graydon Hoare is a software developer who created the Rust programming language in 2006 while working at Mozilla. He served as the project's lead until stepping down in 2013.

## Key Points

- Created Rust as a personal project in 2006, reportedly inspired by frustration with a broken elevator's software.
- Named the language after the rust fungus, noting it is "over-engineered for survival."
- Cited influences from 1970s–1990s languages including CLU, BETA, Mesa, Erlang, and Newsqueak.
- Mozilla officially sponsored the project in 2009 after Hoare began speaking about it internally.
- Stepped down from Rust leadership in 2013; the project then evolved under a federated core team.
