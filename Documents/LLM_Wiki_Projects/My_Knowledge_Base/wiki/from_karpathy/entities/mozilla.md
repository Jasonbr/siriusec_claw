# Mozilla

## Summary

Mozilla is a free-software community and foundation best known for creating the Firefox web browser. It was the original sponsor of the Rust programming language and played a central role in its early development and the Servo browser engine project.

## Key Points

- Mozilla employee Graydon Hoare created Rust as a personal project in 2006; Mozilla officially sponsored it in 2009.
- Executive Brendan Eich and other Mozilla leaders placed engineers on the Rust project to explore a safe browser engine.
- Mozilla co-developed the Servo browser engine with Samsung, using Rust as its implementation language.
- Rust code first shipped in Firefox in 2016; Servo components appeared in Firefox 57 (2017) as part of the Quantum project.
- In August 2020, Mozilla laid off 250 employees, disbanding the Servo team and raising concerns about Rust's future.
