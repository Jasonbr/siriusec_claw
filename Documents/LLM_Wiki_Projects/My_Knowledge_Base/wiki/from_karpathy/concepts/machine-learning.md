# Machine Learning

## Summary

Machine learning is the study of programs that improve their performance on a given task automatically through experience. It is a core subfield of artificial intelligence, encompassing supervised, unsupervised, reinforcement, and transfer learning.

## Key Points

- Supervised learning requires labeled training data and includes classification and regression tasks.
- Unsupervised learning finds patterns in unlabeled data.
- Reinforcement learning trains agents through rewards and punishments for good and bad responses.
- Transfer learning applies knowledge gained from one problem to a new problem.
- Deep learning is a subset of machine learning that uses multi-layer neural networks.
- Computational learning theory assesses learners by computational complexity, sample complexity, and optimization.
