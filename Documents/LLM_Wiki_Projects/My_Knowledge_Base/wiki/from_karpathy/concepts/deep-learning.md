# Deep Learning

## Summary

Deep learning is a subset of machine learning that uses artificial neural networks with multiple layers to progressively extract higher-level features from raw input. It has driven breakthroughs in computer vision, speech recognition, natural language processing, and generative AI.

## Key Points

- Deep neural networks have multiple layers between inputs and outputs.
- Lower layers typically detect simple patterns (edges, curves); higher layers detect complex concepts (digits, faces, objects).
- The 2012–2015 deep learning revolution was enabled by two factors: GPU acceleration (100x speedup) and large curated datasets like ImageNet.
- Key architectures include CNNs for vision, RNNs/LSTMs for sequences, and transformers for language.
- Transformer architecture (post-2017) became the dominant foundation for large language models.
