# Computer Vision

## Summary

Computer vision is the ability of AI systems to analyze and interpret visual input from the world. It includes tasks such as image classification, object recognition, facial recognition, and motion tracking.

## Key Points

- Computer vision is a subfield of machine perception, using input from cameras, lidar, radar, and other sensors.
- Convolutional neural networks (CNNs) are the dominant architecture for vision tasks.
- Key applications include image classification, facial recognition (FaceID, DeepFace, FaceNet), object tracking, and robotic perception.
- Deep learning has profoundly improved computer vision performance, with ImageNet serving as a critical benchmark dataset.
- Vision is increasingly integrated into multimodal AI systems that process images, video, and text together.
