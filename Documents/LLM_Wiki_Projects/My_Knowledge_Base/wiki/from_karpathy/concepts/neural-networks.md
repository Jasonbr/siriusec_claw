# Neural Networks

## Summary

Artificial neural networks are computational models inspired by biological brains, consisting of interconnected nodes (artificial neurons) that process signals through weighted connections. They are the foundation of modern deep learning.

## Key Points

- A neural network has an input layer, one or more hidden layers, and an output layer.
- Networks with at least two hidden layers are typically called deep neural networks.
- Learning algorithms use local search (e.g., backpropagation) to adjust weights and minimize error.
- Feedforward networks pass signals in one direction; recurrent networks (RNNs) feed output back to the input for sequence modeling.
- Long short-term memory (LSTM) networks address the vanishing gradient problem in RNNs.
- Convolutional neural networks (CNNs) use kernel layers to efficiently process local patterns, especially in images.
