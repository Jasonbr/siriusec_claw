# 竞品分析参考指南

## 常见产品类型分析要点

### SaaS 产品
- 免费套餐与付费套餐对比
- 按用户数/功能/存储空间的定价梯度
- API 开放程度
- 集成能力（第三方应用）

### 消费类产品
- 用户评价与口碑
- 社交媒体影响力
- 渠道策略
- 品牌定位

### 开源项目
- Star 数量与趋势
- 贡献者数量
- 社区活跃度
- 商业化模式

## 信息提取技巧

### 从首页提取
- 产品 Slogan（价值主张）
- 核心功能展示
- 目标用户描述
- CTA 按钮（试用/购买）

### 从定价页提取
- 价格档次
- 功能对比表
- 免费额度
- 优惠策略

### 从博客/新闻提取
- 产品发展方向
- 近期动态
- 用户案例
- 行业观点

### 从文档提取
- 技术架构
- API 能力
- 集成方式
- 限制条件

## 分析框架

### SWOT 分析
- **Strengths（优势）**：核心竞争力
- **Weaknesses（劣势）**：不足之处
- **Opportunities（机会）**：市场机会
- **Threats（威胁）**：竞争风险

### 波特五力模型
- 现有竞争者竞争程度
- 潜在进入者威胁
- 替代品威胁
- 供应商议价能力
- 买方议价能力

### 价值链分析
- 产品开发
- 营销销售
- 客户服务
- 技术支持
