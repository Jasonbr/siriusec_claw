# 网页爬取与竞品分析

## 核心能力

1. **网页内容抓取** - 抓取指定网页的文本、标题、链接、图片等
2. **结构化提取** - 提取产品功能、价格、特点等关键信息
3. **竞品对比分析** - 多维度对比分析，生成报告

## 工具选择

优先使用内置工具：
- `fetch_content` - 抓取网页内容（首选）
- `search_web` - 搜索相关信息
- `read_file` - 读取本地文件

## 工作流程

### 1. 网页内容抓取

```
步骤：
1. 使用 fetch_content 抓取目标网页
2. 提取关键信息：标题、正文、产品特性、价格等
3. 整理为结构化格式
```

### 2. 竞品分析流程

```
步骤：
1. 收集所有竞品网址
2. 逐一抓取每个竞品页面
3. 提取关键维度信息
4. 生成对比矩阵
5. 输出分析报告
```

## 分析维度

产品分析关注以下维度：

| 维度 | 说明 |
|------|------|
| 产品定位 | 核心价值主张、目标用户 |
| 核心功能 | 主要功能列表、特色功能 |
| 定价策略 | 价格区间、套餐设计、免费方案 |
| 用户群体 | 目标用户画像、使用场景 |
| 技术特点 | 技术栈、架构特点 |
| 市场表现 | 用户量、市场份额、增长趋势 |
| 营销策略 | 获客渠道、推广方式 |
| 优劣势 | 长处与短处 |

## 执行示例

**用户请求**：分析 notional.so、obsidian.md、roamresearch.com 这三个笔记产品

**执行步骤**：
1. 并行抓取三个网站首页和产品页
2. 提取每个产品的功能、定价、特点
3. 生成对比表格
4. 撰写分析报告

## 注意事项

1. **合规性** - 遵守 robots.txt，不抓取敏感数据
2. **时效性** - 注明信息抓取时间，数据可能已更新
3. **客观性** - 基于公开信息分析，避免主观臆断
4. **完整性** - 尽量覆盖主要竞品，避免遗漏重要玩家
