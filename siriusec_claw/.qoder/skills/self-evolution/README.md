# Self-Evolution Skill

## 自我进化技能

这是一个使 AI 能够持续学习和改进的智能技能。

### 核心功能

1. **用户偏好学习**
   - 沟通风格适应
   - 专业领域识别
   - 术语和表达习惯记忆

2. **反思机制**
   - 对话质量评估
   - 改进点识别
   - 策略调整

3. **自适应优化**
   - 回答深度调整
   - 代码风格匹配
   - 解释方式优化

4. **知识积累**
   - 模式提取
   - 知识库构建
   - 持续更新

### 使用方法

此技能安装后自动生效，AI 会在每次对话中：
- 分析用户反馈
- 调整响应策略
- 积累用户知识
- 持续自我改进

### 配置选项

在 `skill.yaml` 中可以调整：
- `learning_mode`: 是否启用学习模式
- `reflection_enabled`: 是否启用反思
- `adaptation_rate`: 适应速率 (0-1)
- `memory_retention`: 记忆保留数量
